# Skills

One directory per skill, each containing a `SKILL.md` and any files it links
to. Run `../scripts/list-skills.sh` to print this list from the source.

- **[create-skill](./create-skill/SKILL.md)** — Author or revise a skill in
  this repo: establish the failure it fixes, the trigger phrases that reach it,
  and the boundary against neighbouring skills, then scaffold and validate it.

To add one, see [AGENTS.md](../AGENTS.md).
